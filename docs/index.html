A small, open-source experiment +

This is an independent Strudel-powered web demo, not the native REZ macOS application. It has its own code, build and repository. No microphone, MIDI device, analytics or account access is used.

This version plays the acid bass line only. The original full User Acid 168 code, drums included, is preserved as reference source. The separate recorded-loop player uses four local WAV excerpts and stops the acid line when started.

Built with Strudel. Licensed under AGPL-3.0-or-later. Source code & licenses. Phone layout is supported; real-device audio compatibility is still being tested.
